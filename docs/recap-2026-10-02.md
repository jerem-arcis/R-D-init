## Contexte

Structure organisationnelle SAP Onoré :

- Société → Division
- Société → Organisation commerciale → Canal de distribution

Une autre société peut rejoindre SAP (ex. société `0060`, divisions `2860` production et
`2861` entrepôt, organisation commerciale `OC60`). L'app doit alors limiter chaque
utilisateur aux divisions, organisations commerciales, canaux et dossiers de sa société.

## Sources de données ajoutées

| Source | Table / connecteur | Colonnes utiles |
|---|---|---|
| Société | `cr04e_societereferentiel` | `cr04e_ste`, `cr04e_nomsociete`, `cr04e_groupeadmin`, `cr04e_groupeadv`, `cr04e_groupecommerce`, `cr04e_groupeindustrie`, `cr04e_groupequalite` |
| Division | `cr04e_divisionusine` (existante) | + `cr04e_societe`, `cr04e_type` (`PROD` / `STOCK`) |
| Organisation commerciale | `cr04e_organisationcommercialereferentiel` | `cr04e_orgco`, `cr04e_designation`, `cr04e_nomsociete` |
| Canal de distribution | `cr04e_canaldedistributionreferentiel` | `cr04e_canal`, `cr04e_designation`, `cr04e_orgco` |
| Groupes Entra | connecteur `shared_office365groups` | `ListGroupMembers` |

Les liens entre tables sont des **codes texte** (pas de lookup), comparés sans espaces ni
casse. L'organisation commerciale se rattache à la société par son code, à défaut par son nom.

Commande utilisée pour le connecteur (syntaxe `pac code`, différente de la doc `pa app`) :

```powershell
pac code add-data-source -a "shared_office365groups" -c "<connection-id>"
```

## ✅ Lot 1 — Périmètre société et droits par groupe

### Règle de base
- Les colonnes de groupes de la table société contiennent des **Object ID de groupes Entra**
  (plusieurs possibles, séparés par `;`).
- **Société ouverte** (aucun groupe renseigné) : visible et modifiable par tous. Tant que rien
  n'est renseigné, l'app se comporte comme avant.
- **Société cloisonnée** (au moins un groupe renseigné) : visible seulement par les membres de
  ses groupes. Une colonne vide signifie « personne n'a ce rôle », pas « tout le monde ».
- L'appartenance est résolue au démarrage par `ListGroupMembers` sur chaque groupe (fonctionne
  pour les groupes de sécurité et les groupes M365). Un groupe introuvable compte comme « non
  membre » et un avertissement s'affiche dans le menu : une erreur n'ouvre jamais l'accès.

### Dossiers (DE, DS, FL)
- La société d'un dossier est **déduite de sa division** (rien ajouté sur `cr04e_projet`).
- Listes, tableau de bord et liens directs ne montrent que les dossiers de mes sociétés ; un
  dossier hors périmètre ouvert par lien affiche « Accès refusé ».
- Un dossier sans division (ex. DE tout juste remontée de beCPG) reste visible par tous.

### Listes déroulantes
| Liste | Règle |
|---|---|
| Divisions DE | Type `PROD` de mes sociétés. Repli sur les 4 sites historiques tant qu'aucune division n'est typée `PROD` |
| Sites de stockage FL | Type `STOCK` de la société du dossier ; toutes ses divisions si aucune `STOCK` |
| Divisions DS | Toutes les divisions de mes sociétés (règles métier à venir) |
| Canaux FL | Canaux des organisations commerciales de la société du dossier, dédoublonnés par code. Repli sur l'ancienne liste option-set tant que la table est vide |
| Origine de fabrication FL | Mêmes divisions que la DE |

Une valeur déjà enregistrée qui sort du périmètre reste affichée, jamais effacée.

### Droits sur la FL
| Groupe | Peut modifier et viser |
|---|---|
| ADV | Bloc Supply Chain |
| Industrie | Bloc Industriel |
| Commerce | Bloc Commerce |
| Qualité | Rien pour l'instant (bloc à venir) |
| Admin | Tout |

Le reste de la fiche reste visible en lecture seule. Appliqué aux deux vues (par service et
complète) et à la barre de visas.

### DE et DS
Pas de restriction par métier : tout utilisateur qui voit la société peut créer et traiter.

### Onglet Admin
- Visible seulement pour les membres d'un groupe admin (ouvert à tous tant qu'aucun groupe
  admin n'est renseigné).
- Nouveau groupe **« Structure SAP »** : Sociétés, Organisations commerciales, Canaux de
  distribution, Divisions — limité aux lignes des sociétés que j'administre.
- **Modification seule** (ni ajout ni suppression, les lignes viennent de SAP) : désignations,
  identifiants de groupes (format GUID contrôlé), type de division par menu déroulant
  (Sans type / PROD / STOCK).
- L'ancienne liste « Canaux de distribution » (option-set) est retirée de l'Admin.

### Menu
Le nom de la société remplace « BONCOLAC » quand l'utilisateur n'en voit qu'une.

## ✅ Lot 2 — Verrou sur erreur d'envoi SAP

### DE et DS
Dès que `cr04e_fluxenvoiede` vaut « erreur » :
- la demande est **figée pour tout le monde, admins compris** : champs en lecture seule, plus
  de bouton « Enregistrer brouillon » ni « Envoyer vers SAP » ;
- un bandeau rouge l'indique ;
- le bouton de test « Passer à l'étape suivante » de la liste est masqué.

Le statut est relu sur Dataverse à l'ouverture (y compris depuis un brouillon local) et juste
après un envoi en échec. Déblocage : uniquement en corrigeant la colonne dans Dataverse.

### FL
Dès que `cr04e_fluxenvoiefl` vaut « erreur » :
- **non-admin** : fiche entièrement en lecture seule, envoi désactivé ;
- **admin de la société du dossier** : tous les champs redeviennent modifiables, même ceux des
  blocs déjà visés, et le bouton devient « Relancer la création SAP ». Les visas restent posés.

## ⚠️ Points d'attention à la publication

1. **Connexion et droits** : chaque utilisateur doit accepter la connexion Office 365 Groups
   et avoir la lecture Dataverse sur les quatre tables. Sinon l'app affiche « Droits d'accès
   indisponibles » au lieu de s'ouvrir sans cloisonnement.
2. **DE/DS déjà en erreur** : elles seront figées dès la publication.
3. **Tant qu'aucun groupe admin n'est renseigné**, tout le monde est considéré admin (onglet
   Admin ouvert, FL en erreur modifiable et relançable par tous).
4. **Premier groupe à saisir** : le groupe Admin de sa propre société, avec un groupe dont on
   est membre. Sinon on perd l'accès à l'onglet Admin (correction dans Dataverse).
5. **Sites de stockage FL** : la liste Olano codée en dur est remplacée par les divisions de
   la table.
6. **Nouvelle division PROD** : sélectionnable en DE, mais les calculs automatiques
   (hiérarchie, classe de valorisation, centre de profit) ne connaissent que les 4 sites
   historiques.

## Limites connues

- Le cloisonnement est appliqué **dans l'app** : un accès direct à Dataverse permet toujours de
  lire les autres sociétés. Un cloisonnement opposable demandera des rôles de sécurité Dataverse.
- Seuls les **membres directs** d'un groupe sont reconnus (pas les groupes imbriqués), 999
  membres maximum par groupe.
- La page `TraiterDE` (brouillons locaux) n'est pas cloisonnée.
- Si l'envoi SAP ne démarre même pas (réseau, URL du flux), rien n'est écrit dans la colonne
  de statut : la demande n'est pas figée.

## Tester le cloisonnement

- **En local** (jamais en build publié), dans la console du navigateur puis recharger :
  `localStorage.setItem('perimetre_groupes', '<guid>;<guid>')`.
- **Une fois publié** : créer un groupe de sécurité Entra, s'y ajouter, coller son Object ID
  dans Admin → Structure SAP → Sociétés.
